The command line tool and MCP server

They run on your machine and have no telemetry. Without a licence key they make no network calls at all. Your code, findings and secrets stay with you.

Solo and Team

If you set SIGSHIP_KEY, the tool sends two things to api.sigship.dev: your licence key, and a one-way fingerprint of the repository made from its git address mixed with your key. It sends no code, file names or findings.

We pass the key to Polar to check it and to count the repository against your plan's limit. We keep the fingerprint and Polar's activation ID so each repository is counted once. The Pro pack is cached on your machine for 24 hours.

This website

This site uses Cloudflare Web Analytics, which counts visits without cookies.

Payments

Polar is the merchant of record. Polar collects your payment details and shares your name, email and order with us so we can provide the service.

Pilot review

If you buy a pilot review, you choose what code to share with us. We use it only for that review and delete it when the review ends, unless you ask us to keep it.
