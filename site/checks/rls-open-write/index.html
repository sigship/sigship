SEV-1: blocks launch

A database policy lets anyone write

What goes wrong

Row level security is on, but this policy says yes to everyone, so a stranger can edit or delete your data.

How to fix it

Replace true with a real condition, such as auth.uid() = user_id, on both the using and with check clauses.

Check your app

Run npx sigship in your project. It runs on your machine and reports this check as rls-open-write.
