Check my app
Cloud API · preview

Connect SIGSHIP to anything. 

Start checks, read results and badge status from your own tools. Preview — the API ships with Cloud, and endpoints may change before launch.

Endpoints

POST/v1/scansStart a check for an app
GET/v1/scans/{id}Get a check's result
GET/v1/appsList your connected apps
GET/v1/apps/{id}/badgeBadge status and last pass date
POST/v1/webhooksGet notified when a check fails

Authentication

Create a key in your Cloud dashboard and send it as a Bearer token. Keep it on your server — SIGSHIP would flag it otherwise.

Start a check
curl https://api.sigship.dev/v1/scans \
  -H "Authorization: Bearer $SIGSHIP_KEY" \
  -d '{ "app": "plantpal.app" }'
Start a check
const res = await fetch("https://api.sigship.dev/v1/scans", {
  method: "POST",
  headers: { Authorization: `Bearer ${process.env.SIGSHIP_KEY}` },
  body: JSON.stringify({ app: "plantpal.app" }),
});
const scan = await res.json(); // { id, verdict: "GO" | "NO-GO", findings }
Start a check
import os, requests
r = requests.post(
  "https://api.sigship.dev/v1/scans",
  headers={"Authorization": f"Bearer {os.environ['SIGSHIP_KEY']}"},
  json={"app": "plantpal.app"},
)
print(r.json()["verdict"])
Response
{
  "id": "scn_8f2a",
  "verdict": "NO-GO",
  "findings": [
    { "id": "rls-missing", "level": "fix_now", "file": "001_init.sql" }
  ]
}
