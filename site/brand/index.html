The flags

The home page spells SIGSHIP in flags from the International Code of Signals. The mark is flag P, the Blue Peter, which a ship raises when it is about to sail. A signal in Unix is a message a program has to act on. SIGSHIP is both.

Please don't

  • Recolour flag P or change its white centre.
  • Stretch, rotate or add effects to the logo.
  • Use the logo to suggest SIGSHIP has reviewed or approved an app.
