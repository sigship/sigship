The 17 checks

The 17 mistakes AI tools make most. We check every one.

Hover a card to see the fix. No jargon — just what could happen and what to do.

🔑Fix nowSEV-1

A live secret is sitting in your codesecret-in-code

Anyone who reads your code or your site’s JavaScript can copy it and spend your money.

The fix

Rotate the key, then move it to a server-side environment variable.

secret-in-code
How to fix it →
🔑Fix nowSEV-1

Your .env file is committedenv-file-committed

Your .env file is in the repo, so every password in it is public.

The fix

Remove .env from git, add it to .gitignore, and rotate every value.

env-file-committed
How to fix it →
🔑Fix nowSEV-1

A server secret has a browser-visible namepublic-env-secret

A NEXT_PUBLIC_ or VITE_ name ships the secret to every visitor’s browser.

The fix

Drop the public prefix and move the call to a server route.

public-env-secret
How to fix it →
✨Fix nowSEV-1

Your AI key runs in the browserai-key-in-browser

Strangers copy your key from the browser and use your OpenAI credits for free.

The fix

Call the AI from a server route that holds the key.

ai-key-in-browser
How to fix it →
🗂️Fix nowSEV-1

A database table has no row level securityrls-missing

Anyone with your public key can read every row in this table.

The fix

Turn on row level security and add an owner-only policy.

rls-missing
How to fix it →
🗂️Fix nowSEV-1

A database policy lets anyone writerls-open-write

The lock exists, but it’s set to “allow all”. Anyone can edit or delete.

The fix

Replace true with a real condition, like auth.uid() = user_id.

rls-open-write

The fix

Verify every Stripe event with its signing secret.

stripe-webhook-unverified

For AI agents

Your AI checks its own work before it says “done”.

Plug SIGSHIP into Claude Code, Cursor, Windsurf, Copilot or any tool that speaks MCP — the standard way AI tools connect to helpers. Your agent runs the check and keeps fixing until it's Ready.

Run this once in your terminal.
claude mcp add sigship -- npx -y sigship mcp
Add to .cursor/mcp.json
{ "mcpServers": { "sigship": { "command": "npx", "args": ["-y", "sigship", "mcp"] } } }
Add to ~/.codeium/windsurf/mcp_config.json
{ "mcpServers": { "sigship": { "command": "npx", "args": ["-y", "sigship", "mcp"] } } }
Add to .vscode/mcp.json
{ "servers": { "sigship": { "command": "npx", "args": ["-y", "sigship", "mcp"] } } }
Run in your terminal.
gemini mcp add sigship npx -y sigship mcp
Add to ~/.codex/config.toml
[mcp_servers.sigship]
command = "npx"
args = ["-y", "sigship", "mcp"]
Paste into your Lovable chat after running the check.
npx sigship --prompt
