01 · stripe-webhook.ts:3

Your Stripe webhook accepts anything

Someone posts a fake "payment succeeded" event to your endpoint and gets your paid plan for free.

The fix. Verify every event with stripe.webhooks.constructEvent, using the raw request body and your webhook signing secret, before you act on it.

A database table has no row level security

Anyone with your public Supabase key can read this table. That key ships in your JavaScript.

The fix. Add "alter table <name> enable row level security;" in a new migration, then write a policy that limits each row to its owner.

04LimitsFig. 4

What a GO doesn't mean.

A GO means these checks found nothing that blocks launch. It does not prove the app is safe.

  1. FR-1

    It looks for known mistakes, so it can miss a real problem, or warn about code that's actually fine. Tell us when it's wrong

  2. FR-2

    It reads your code, so it can't see settings you changed only on a website dashboard, like Supabase. Run your database provider's own security advisor too.

  3. FR-3

    It checks your code, not the live website your users visit.

?QuestionsNew to this?

Questions, answered simply. No jargon, promise.

What is SIGSHIP?

A free safety check for apps built with AI tools like Lovable, Bolt, Cursor, Replit, v0 and Claude Code. It reads your app's code on your own computer and tells you, in plain English, what could leak, break or cost you money once real people use it, and how to fix each one.

Is my vibe-coded app safe to launch?

Maybe not yet. AI tools often leave the same few mistakes behind: API keys in the code, database tables anyone can read, payment events nobody checks, and AI features with no spending limit. SIGSHIP looks for those and says GO when none are left. A GO doesn't prove the app is safe, but it means these common mistakes are gone.

Does it work with Lovable, Bolt, Replit and v0?

Yes. Connect your project to GitHub (most AI builders have a button for it), download the code to your computer, and run npx sigship in that folder. It also works in Cursor, Claude Code and any project with JavaScript or TypeScript code.

Do I need to know how to code?

No. You run one command, and it gives you one prompt to paste into your AI tool, which makes the fixes for you. Then you run the check again until it says GO.

Does SIGSHIP upload my code?

No. The free tool runs entirely on your computer and makes no network calls. Your code, keys and results never leave your machine.

Is it really free?

Yes. The tool is open source under the MIT licence, with no signup, no card and no limit on projects. Paid plans with extra checks are on the waitlist.

09Ready to sailFig. 9

Ships raise a flag before they leave port. Software never did.

In harbour, flag P, the Blue Peter, tells everyone the vessel is about to sail. In computing, a "signal" is a message a running program has to act on. SIGSHIP is both: one clear message that this app is ready to leave port, or that it isn't yet.
