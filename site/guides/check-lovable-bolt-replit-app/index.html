How to check an app built with Lovable, Bolt, Replit or v0

Your app lives inside an AI builder, but checking it takes the code on your own computer. It takes about five minutes, and you don't need to know how to code.

1. Get your code onto your computer

  • Lovable or Bolt: use the GitHub button in the builder to connect your project to a GitHub repository. Then, on GitHub, click Code and Download ZIP, and unzip it.
  • Replit: download your project as a ZIP file from the Files menu, or connect it to GitHub and download from there.
  • v0: download the generated code, or push it to GitHub, and download the project.

Button names change from time to time. If you can't find them, ask the builder's own assistant: "How do I download my code or sync it to GitHub?"

2. Install Node.js once

Download Node.js version 22 or newer from nodejs.org and install it like any app. It's free.

3. Run the check

Open the Terminal app (Mac) or PowerShell (Windows). Type cd and a space, drag your project folder into the window, and press Enter. Then run:

npx sigship ui

This opens a private page in your browser with the verdict, every problem in plain English, and a button to copy the fixes. It runs on your computer only. Nothing is uploaded.

4. Let your AI builder fix it

Copy the fix prompt and paste it into the builder's chat. When it's done, sync and download again, and re-run the check until it says GO.

5. Check the settings in your dashboards too

SIGSHIP reads your code, so it can't see settings you changed only on a website, like Supabase table rules made in the dashboard. Run Supabase's own security advisor as well. Supabase RLS, explained simply.

Questions

Can SIGSHIP check my Lovable app without downloading it?

Not yet. The free tool reads code on your computer, so you download the project first. SIGSHIP Cloud, on the waitlist, is planned to connect to builders directly.

Will running SIGSHIP change my app?

No. It only reads your files. Your AI tool makes the fixes.
