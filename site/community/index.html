Getting help

Where should I ask a question?

Start a thread in GitHub Discussions. Others can learn from the answer too. For anything private, email support@sigship.dev.

What should a bug report include?

Your SIGSHIP version (npx sigship --version), your operating system and Node.js version, and the smallest code that shows the problem. Never include real keys or customer data.

Can I suggest a new check?

Yes, please. Tell us what goes wrong in production and what it looks like in code, using the "Idea for a check" form on GitHub.
