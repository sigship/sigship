AI agents

Your AI checks its own work. 

SIGSHIP speaks MCP, the standard way AI coding tools connect to helpers. Add it once and your agent won’t say “done” until the check says Ready.

sigship_check
Runs all 17 checks and returns what to fix.
sigship_explain
Explains one finding in plain words with a fix.
AGENTS.md rule (added by npx sigship init)
## Definition of done

Before saying work is finished, run `npx sigship`.
If it is not GO, fix what it reports and run it again. Only say the work is done after it exits 0.
Claude Code
Run this once in your terminal.
claude mcp add sigship -- npx -y sigship mcp
Cursor
Add to .cursor/mcp.json
{ "mcpServers": { "sigship": { "command": "npx", "args": ["-y", "sigship", "mcp"] } } }
Windsurf
Add to ~/.codeium/windsurf/mcp_config.json
{ "mcpServers": { "sigship": { "command": "npx", "args": ["-y", "sigship", "mcp"] } } }
GitHub Copilot
Add to .vscode/mcp.json
{ "servers": { "sigship": { "command": "npx", "args": ["-y", "sigship", "mcp"] } } }
Gemini CLI
Run in your terminal.
gemini mcp add sigship npx -y sigship mcp
Codex
Add to ~/.codex/config.toml
[mcp_servers.sigship]
command = "npx"
args = ["-y", "sigship", "mcp"]
Lovable
Paste into your Lovable chat after running the check.
npx sigship --prompt
